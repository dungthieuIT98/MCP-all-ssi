2. list_catalogs
   Mô tả: Liệt kê tất cả catalog.

   Input: (không có tham số)

   Kết quả thực tế: ["memory", "mysql", "system"]

--------------------------------------------------------------------------------
3. list_schemas
   Mô tả: Liệt kê schemas trong một catalog.

   Input:
     catalog (optional, string)

   Ví dụ:
     { "catalog": "mysql" }
     { "catalog": "memory" }
     { "catalog": "system" }

   Kết quả thực tế:
     mysql  → ["demo", "information_schema", "performance_schema"]
     memory → ["default", "information_schema"]
     system → ["information_schema", "jdbc", "metadata", "runtime"]

--------------------------------------------------------------------------------
4. list_tables
   Mô tả: Liệt kê các table/view trong catalog/schema.

   Input:
     catalog (optional, string)
     schema  (optional, string)

   Ví dụ:
     { "catalog": "mysql",  "schema": "demo" }
     { "catalog": "system", "schema": "runtime" }
     { "catalog": "system", "schema": "metadata" }

   Kết quả thực tế:
     mysql.demo    → [bonds, companies, dividends, fund_holdings, market_indices,
                      portfolios, stock_prices, stocks, transactions, watchlists]
     system.runtime  → [nodes, optimizer_rule_stats, queries, tasks, transactions]
     system.metadata → [analyze_properties, catalogs, column_properties,
                         materialized_view_properties, materialized_views,
                         schema_properties, table_comments, table_properties]

--------------------------------------------------------------------------------
5. get_table_schema
   Mô tả: Xem cấu trúc column của một table.

   Input:
     table   (REQUIRED, string)
     catalog (optional, string)
     schema  (optional, string)

   Ví dụ:
     { "table": "mysql.demo.stocks" }
     { "table": "mysql.demo.stock_prices" }
     { "table": "mysql.demo.transactions" }
     { "table": "mysql.demo.portfolios" }
     { "table": "mysql.demo.companies" }
     { "table": "mysql.demo.dividends" }
     { "table": "mysql.demo.fund_holdings" }
     { "table": "mysql.demo.market_indices" }
     { "table": "mysql.demo.bonds" }
     { "table": "mysql.demo.watchlists" }

   Schema thực tế:
     stocks        : id, symbol(varchar10), revenue, net_income, eps, pe_ratio, fiscal_year
     stock_prices  : id, symbol(varchar10), trade_date, open_price, close_price,
                     high_price, low_price, volume(bigint)
     transactions  : id, portfolio_id, symbol(varchar10), tx_type(varchar10),
                     quantity, price, tx_date, fee
     portfolios    : id, portfolio_name, owner, created_date, total_value, currency
     companies     : id, symbol(varchar10), company_name, sector, exchange, ipo_date, created_at
     dividends     : id, symbol(varchar10), ex_date, pay_date, amount, currency
     fund_holdings : id, fund_name, symbol(varchar10), shares(bigint), market_value,
                     weight_pct, report_date
     market_indices: id, index_name, index_code, trade_date, close_value, change_pct
     bonds         : id, bond_code, issuer, face_value, coupon_rate, maturity_date, credit_rating
     watchlists    : id, user_name, symbol(varchar10), added_date, target_price, note

7. execute_query
   Mô tả: Thực thi SQL query trên Trino (default read-only).

   Input:
     query (REQUIRED, string)

   Ví dụ READ-ONLY:
     -- Danh sách công ty
     { "query": "SELECT symbol, company_name, sector, exchange FROM mysql.demo.companies ORDER BY symbol" }

     -- Giá cổ phiếu ngày gần nhất
     { "query": "SELECT symbol, close_price, volume, trade_date FROM mysql.demo.stock_prices ORDER BY trade_date DESC LIMIT 10" }

     -- Giá VNM 5 ngày gần nhất
     { "query": "SELECT trade_date, open_price, close_price, high_price, low_price, volume FROM mysql.demo.stock_prices WHERE symbol = 'VNM' ORDER BY trade_date DESC LIMIT 5" }

     -- Top 5 cổ phiếu volume cao nhất
     { "query": "SELECT symbol, SUM(volume) AS total_volume FROM mysql.demo.stock_prices GROUP BY symbol ORDER BY total_volume DESC LIMIT 5" }

     -- Danh mục đầu tư và giá trị
     { "query": "SELECT portfolio_name, owner, total_value, currency FROM mysql.demo.portfolios ORDER BY total_value DESC" }

     -- Lịch sử giao dịch của portfolio_id=1
     { "query": "SELECT symbol, tx_type, quantity, price, fee, tx_date FROM mysql.demo.transactions WHERE portfolio_id = 1 ORDER BY tx_date DESC" }

     -- Cổ tức sắp tới
     { "query": "SELECT symbol, amount, currency, ex_date, pay_date FROM mysql.demo.dividends ORDER BY ex_date" }

     -- Tỷ lệ nắm giữ của quỹ VFMVF1
     { "query": "SELECT symbol, shares, market_value, weight_pct FROM mysql.demo.fund_holdings WHERE fund_name = 'VFMVF1' ORDER BY weight_pct DESC" }

     -- Chỉ số thị trường
     { "query": "SELECT index_code, index_name, close_value, change_pct, trade_date FROM mysql.demo.market_indices ORDER BY trade_date DESC, index_code" }

     -- Trái phiếu theo lãi suất
     { "query": "SELECT bond_code, issuer, coupon_rate, maturity_date, credit_rating FROM mysql.demo.bonds ORDER BY coupon_rate DESC" }

     -- Watchlist của Nguyen Van A
     { "query": "SELECT symbol, target_price, added_date, note FROM mysql.demo.watchlists WHERE user_name = 'Nguyen Van A'" }

     -- Tài chính doanh nghiệp FY2025
     { "query": "SELECT symbol, revenue, net_income, eps, pe_ratio FROM mysql.demo.stocks WHERE fiscal_year = 2025 ORDER BY pe_ratio" }

     -- Join giá + công ty
     { "query": "SELECT c.symbol, c.company_name, c.sector, sp.close_price, sp.volume, sp.trade_date FROM mysql.demo.companies c JOIN mysql.demo.stock_prices sp ON c.symbol = sp.symbol ORDER BY sp.trade_date DESC, c.symbol LIMIT 20" }

     -- Tổng giá trị giao dịch theo loại
     { "query": "SELECT tx_type, COUNT(*) AS count, SUM(quantity * price) AS total_value FROM mysql.demo.transactions GROUP BY tx_type" }

     -- SHOW / DESCRIBE
     { "query": "SHOW SCHEMAS FROM mysql" }
     { "query": "SHOW TABLES FROM mysql.demo" }
     { "query": "DESCRIBE mysql.demo.stock_prices" }
     { "query": "SELECT catalog_name FROM system.metadata.catalogs" }

8. explain_query
   Mô tả: Phân tích execution plan của query.

   Input:
     query  (REQUIRED, string)
     format (optional, string): LOGICAL | DISTRIBUTED | VALIDATE | IO

   Ví dụ:
     { "query": "SELECT symbol, close_price FROM mysql.demo.stock_prices WHERE symbol = 'VNM'" }

     { "query": "SELECT c.company_name, sp.close_price, sp.volume FROM mysql.demo.companies c JOIN mysql.demo.stock_prices sp ON c.symbol = sp.symbol", "format": "DISTRIBUTED" }

     { "query": "SELECT symbol, SUM(volume) FROM mysql.demo.stock_prices GROUP BY symbol", "format": "LOGICAL" }

     { "query": "SELECT * FROM mysql.demo.transactions WHERE trade_date >= DATE '2026-05-01'", "format": "IO" }

================================================================================
GHI CHÚ CHUNG
================================================================================

Luồng khám phá DB chuẩn với Trino (mysql.demo):
  1. list_catalogs                              → ["memory","mysql","system"]
  2. list_schemas(catalog="mysql")              → ["demo","information_schema",...]
  3. list_tables(catalog="mysql",schema="demo") → [bonds,companies,dividends,...]
  4. sample_table("mysql.demo.stock_prices")    → schema + 5 rows + stats
  5. execute_query("SELECT ...")                → query thực tế

Luồng chuẩn với Superset:
  1. superset_auth_authenticate_user  → lấy token
  2. superset_database_list           → lấy database_id
  3. superset_sqllab_execute_query    → chạy SQL với demo data
  4. superset_dashboard_list          → duyệt dashboards
  5. superset_chart_list              → duyệt charts
